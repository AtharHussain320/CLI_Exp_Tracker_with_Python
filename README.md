#  CLI Expense Tracker

**Aptura Tech Solution — Batch 3 Internship | Week 2 | Task 1**

A practical command-line expense tracking application built with Python.
The project focuses on clean program structure, input validation, persistent
data storage, and useful expense summaries.

---

##  Project Overview

Managing small daily expenses can become difficult when records are scattered
across different places.

This project provides a simple solution by allowing users to record and
analyze their expenses directly from the command line.

The application stores expense records in a local JSON file, making the data
available even after the program is closed.

---

##  Features

-  Add new expenses
-  View complete expense history
-  Search expenses by description
-  Filter expenses by category
-  Calculate monthly spending
-  Generate category-wise spending summary
-  Persistent JSON storage
-  Input validation
-  Handles missing and corrupted JSON files

---

##  Expense Categories

The application includes:

- Other
